# Apibox

## Overview

Start API Boxes from API Box Snapshots. Each API Box serves its Snapshot's API at its own endpoint, with its own state, in real time. Stop, start and delete them.

### Available Operations

* [listApiboxes](#listapiboxes) - List API Boxes
* [createApibox](#createapibox) - Create API Box
* [deleteApibox](#deleteapibox) - Delete API Box
* [getApibox](#getapibox) - Get API Box
* [updateApibox](#updateapibox) - Update API Box
* [getApiboxConnection](#getapiboxconnection) - Get API Box connection
* [startApibox](#startapibox) - Start API Box
* [listApiboxSteps](#listapiboxsteps) - List API Box Steps
* [stopApibox](#stopapibox) - Stop API Box

## createApibox

Creates an API Box from a ready API Box Snapshot and starts it. It returns at once with status starting and the API Box's token; get the API Box until it is running. Send the token in X-Continuous-Token on each request to the API Box's endpoint. The token lasts as long as the API Box, and its connection returns it again. Each API Box has its own state, and runs in real time.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="create-apibox" method="post" path="/v1/apibox" example="bad_request_body" -->
```typescript
import { Continuous } from "@continuous-labs/sdk";

const continuous = new Continuous({
  apiKeyAuth: process.env["CONTINUOUS_API_KEY_AUTH"] ?? "",
});

async function run() {
  const result = await continuous.apibox.createApibox({
    body: {
      metadata: {
        "customer_id": "cust_123",
      },
      name: "billing-sandbox",
      snapshotId: "abs_01J8Z5X4K70000000000000002",
    },
  });

  console.log(result);
}

run();
```

## stopApibox

Stops a running API Box: it saves its state, and releases its runtime; its token stays for the next start. It returns at once with status stopping; get the API Box until it is stopped. A stopped API Box is returned unchanged; a starting one returns 409 apibox_starting.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="stop-apibox" method="post" path="/v1/apibox/{id}/stop" -->
